## 三条硬规则（改任何字串前先过一遍）

1. **菜单字 = 页前缀 + 码**：前缀值 = 页号 + 1（`01`=页0、`02`=页1 …），码 `0x80–0xFF` 是格号。前缀写错不报错，只会画成空白格。
2. **信道名 = 扳机 + 码**：名字槽只有 128 个单字节位、不能写前缀，所以把页0 的两个空码位改造成"扳机"——表位 `0xB5→页4`、`0xC3→页5`（`0x1FE2C` 起 128 项转换表，索引 = 码 − 0x80）。裸 `0x02/0x03` 会被吃成 `0x3F`（问号）。
3. **8×16 / 8×8 小字只认页0 裸码**，不吃页前缀；凡可能被小字绘制的串一律保持英文，否则整串重映射成乱码（v222/v226 两次踩坑都在这）。

## 其它必须遵守的

- **一个槽可能被第二个页面按固定偏移借读**：`0x28E61`（APRS 菜单底部说明 + 信标详情页状态行）、`0x283A1`（APRS 17 标签 + APRS 08 的 SSID）、`0x286B8`（`Slot Time` + 主菜单第 11 项「时间」）、`0x28536`（`Enabled` + APRS 09）。改前先全镜像检索同址引用。
- **改短串必须把槽填满到原厂长度（补空格，不补 0）**，否则行尾会残留上一条像素。
- **计格规则**：ASCII 1 格、页前缀 1 格、汉字 2 格；列表行 12 格，超出会折到上一行同一横坐标。
- **改字库前先离线验字形**：16×16 菜单字在 `spi_font_v218.bin` 里的偏移 = `0xEC02 + 页*0x2000 + 码*0x20`，字模是列优先竖条带（每列 2 字节，低位在上），可与 unifont 逐字节比对。

## 刷机（引导器 / 无界面）

串口 COM3，**115200 8N1**，1024 B/块，169,440 B = **166 块**。

1. 电台关机 → 按住 PTT 开机 → 屏全黑即刷机模式；
2. 握手 `0x39 0x33 0x05 0x10` + 校验，校验初值试 `0x43` / `0x52`，回 `0x06` 即对；
3. 擦除两次（data `0x10` 再 `0x55`），然后逐块 `0x57 + addr(2, BE) + 1024B`；
4. 末次应答常为"无"，属正常；实测 21.2 秒刷完；重复刷安全。

脚本 `scripts/flash_fw.py <固件.bin>`。
